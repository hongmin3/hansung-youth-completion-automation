# 청년 양육 수료내역 디모데 자동입력

Google Sheet의 수료 명단을 읽어 한성교회 디모데 `청년관리 > 교인검색(청년)`에서 교인을 찾고, 검증된 수료 내역만 입력하는 자동화입니다.

## 안전 원칙

- 기본 실행은 **드라이런**이며 디모데에 저장하지 않습니다.
- `--execute`를 명시해야 실제 저장합니다.
- 이름, 군, 팀, 전화번호가 디모데의 한 사람과 정확히 일치해야 진행합니다.
- 교육과정은 정확히 `청년-`으로 시작하는 허용 목록만 선택합니다.
- 전화번호나 과정 매핑이 없으면 건너뜁니다.
- 수료일은 `20260621`, 수료연도는 `2026`, 상태는 `수료`로 입력합니다.
- 강사명은 시트의 `담당자` 값을 사용합니다.
- 이미 같은 교육과정이 있거나 신규 저장이 성공하면 시트의 `입력여부` 체크박스를 체크합니다.

## 현재 확인된 교육과정 매핑

| 시트 구분 | 디모데 교육과정 |
|---|---|
| LTC | 청년-LTC |
| 확신반 | 청년-확신반 |
| 성장반 | 청년-성장반 |
| 성경대학 | 청년-성경대학 |
| 교리대학 | 청년-교리대학 |

`기초반`, `예배학교`, `결혼예비학교`는 사용자 확인에 따라 현재 입력 대상에서 명시적으로 제외했습니다. `EDU_COURSE_MAP`에 값을 추가하더라도 자동 입력하지 않으며, 추후 사용자가 별도로 요청한 뒤 코드를 변경해야 입력됩니다.

## 설치

```bash
cd ~/Desktop/자동화/'새가족 수료여부 자동입력'
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 -m playwright install chromium
cp config.example.py config.py
```

기존 `config.py`가 있다면 덮어쓰지 말고 `config.example.py`에서 새 항목만 옮기세요.

## Google Sheet 체크 권한 설정

1. Google Cloud Console에서 프로젝트를 만듭니다.
2. Google Sheets API를 활성화합니다.
3. OAuth 동의 화면을 구성합니다.
4. Desktop app 유형의 OAuth Client를 만들고 JSON을 다운로드합니다.
5. 파일명을 `credentials.json`으로 바꾸어 프로젝트 폴더에 둡니다.
6. 최초 실제 실행 시 브라우저에서 Google 계정 접근을 승인합니다. 이후 토큰은 `token.json`에 저장됩니다.

`credentials.json`, `token.json`, `config.py`는 `.gitignore`에 포함되어 GitHub에 올라가지 않습니다.

## 설정

`config.py`에서 다음을 확인합니다.

- `SHEET_URL`: 통합 수료 명단 URL. `gid`까지 포함합니다.
- `SHEET_TAB_NAME`: 기본값 `통합 명단`
- `GOOGLE_COOKIES`: CSV 다운로드에 사용할 Google 쿠키
- `DIMODE_URL`, `USER_ID`, `USER_PW`: 디모데 로그인 정보
- `EDU_COURSE_MAP`: 추가로 확인된 정확한 `청년-` 과정 매핑

시트 열은 다음 순서를 사용합니다.

`구분 / 군 / 팀 / 이름 / 핸드폰 / 담당자 / 입력여부`

## 실행

먼저 소수 인원을 드라이런합니다.

```bash
python3 main.py --limit 5
```

결과는 `output/dry_run_plan.csv`에 저장됩니다. 모든 대상의 이름, 소속, 담당자, 교육과정이 맞는지 검토하세요.

전체 드라이런:

```bash
python3 main.py
```

검토가 끝난 뒤 실제 입력:

```bash
python3 main.py --execute
```

처음 실제 실행할 때도 `--limit 1`로 한 명만 처리한 뒤 디모데와 Google Sheet를 직접 확인하는 것을 권장합니다.

```bash
python3 main.py --execute --limit 1
```

## 결과 상태

- `드라이런확인`: 교인을 정확히 찾았으며 실제 저장은 하지 않음
- `입력완료`: 디모데 신규 저장과 시트 체크 완료
- `이미입력됨`: 중복 등록하지 않고 시트만 체크
- `교육과정매핑없음`: 정확한 `청년-` 과정이 없어 차단
- `전화번호없음`: 조회로도 번호를 확정하지 못함
- `정확한교인없음` / `교인복수일치`: 안전하게 건너뜀

## 문제 해결

- 디모데 화면 구조가 바뀌면 선택자가 달라질 수 있습니다. 저장 실패 로그가 나오면 실제 입력을 중단하고 드라이런부터 다시 확인하세요.
- Google Sheet 체크가 실패하면 자동화는 즉시 중단됩니다. 재실행 시 디모데 중복 여부를 확인한 뒤 `입력여부`를 복구합니다.
- 민감정보가 포함된 `config.py`, 브라우저 프로필, 로그, 디버그 파일은 GitHub에 올리지 마세요.
